# 原创素材说明

## 影像

本项目使用 `imagegen` 内置生成工具制作六组原创三联实拍感记忆画面；生成日期为 2026-08-02 至 2026-08-03。源图已从工具默认目录复制到本项目 `assets/source-storyboards/`，之后由 `scripts/slice_storyboards.py` 确定性切分为 18 张 1280×720 WebP 正式镜头。

共同人物设定：林弦，26 岁中国女性，非对称黑色短发、银色耳扣、铁锈橙雨衣和米白高领衫；陶沅，27 岁中国人，短发、黑色摩托夹克和暗红围巾。人物、场景与叙事均为本项目原创，不对应参考视频中的角色。

六组正式生成提示的制作意图：

1. 黎明前的旧剪辑室、林弦侧脸、红铅笔标记纸带；冷青、冷白、深黑与单一橙色。
2. 雨夜公交站、头盔面罩眼部、桥下旧摩托；现实雨夜摄影，不使用霓虹或 HUD。
3. 停业游乐场的两人、将触未触的手与空白票、旋转木马镜面；蓝调向暖橙过渡。
4. 桥下分开的脚印、两只头盔、驶入隧道的摩托与后视镜；作为关系物证。
5. 半开门两侧的争执、一个杯子与两个杯印、冷房间中的橙色门光；作为删除行为的矛盾证据。
6. 两张空白票、磁带机停止键与双波形影子、后视镜中被留下的人；构成三个被删片段。

每组提示均明确要求：原创实拍电影感、三个独立 16:9 画幅、无文字、无字幕、无水印、无 Logo、无品牌、无动漫人物、无廉价赛博朋克 HUD、无霓虹发光。

正式镜头哈希、裁切坐标和源图映射见 `public/assets/shots/shots-manifest.json`。

## 字体

- Noto Sans SC Regular / Bold：本机安装的 Noto Sans SC，用于中文显示并复制进项目。
- Geist Mono：来自既有本地作品集已本地化的 Geist Mono 字体文件，用于时间码与机器标记。

## 声音

声音不含外部音频文件。`src/audioEngine.ts` 使用 Web Audio API 实时合成固定种子磁带噪声、鼓点、机械点击和低频环境床，并经过压缩器与末级限制器控制峰值。

## 参考视频边界

参考视频只用于只读研究快速切镜、分栏、巨字、重复排版、旋转、色彩章节、结构故障帧与节拍层级。参考视频本身、音轨、字幕、水印、人物和画面均未复制、嵌入或重新分发到项目。
