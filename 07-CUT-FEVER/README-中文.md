# CUT//FEVER《失控剪辑室》

![CUT FEVER 界面预览](../docs/previews/07-cut-fever.jpg)

一件介于互动电影、动态海报与实验剪辑台之间的原创本地网页艺术作品。机器只学习了你每一次删除；你需要在失控时间线里找到三段被删记忆，并决定保留或删除它们。

## 直接体验

正式交付后，双击“科幻作品集”里的 `打开《CUT／／FEVER 失控剪辑室》` 快捷方式。作品会通过本机 `127.0.0.1` 打开，不需要登录、API Key 或在线数据库。

关闭时双击合集根目录的 `关闭本地作品服务器`。直接关闭浏览器窗口不会损坏作品。

## 体验流程

1. 点击唯一的未知片段，启动空时间线。
2. 在“正常剪辑”阶段切镜、调速、改变构图。
3. 机器开始插入不属于你的镜头，颜色与分栏升温。
4. 失控阶段里，镜头、遮罩和文字按不同节拍重组。
5. 根据画幅接缝、停留时间和倒回标记寻找三段被删记忆。
6. 对三段记忆分别选择保留或删除，导出三种结局之一。
7. 结局页可下载本次剪辑的 1350×1800 PNG 静态封面。

## 操作

| 操作 | 桌面端 | 手机端 |
|---|---|---|
| 时间线速度 | 滚轮 | 上下滑动 |
| 刮擦预览 | 鼠标横向移动 / 拖动 | 横向滑动 |
| 切镜 | 点击画面 | 点击画面 |
| 节拍切镜 | 空格键 | 双击画面 |
| 暂停自动剪辑 | 长按 | 长按 |
| 构图模式 | 数字键 1—4 / 左侧模式轨 | 底部模式轨 |
| 色彩模式 | C 键 / 左侧色点 | 左侧色点 |
| 键盘刮擦 | ← / →；Shift 加速；Home / End 到边界 | — |
| 键盘冻结 | 按住 H | — |
| 静音 | “声音 / 安全”面板或 M 键 | “声音 / 安全”面板 |

声音默认关闭。只有明确点击“启用程序声音”后，浏览器才会初始化本地 Web Audio；初始化失败时视觉节拍和全部分支仍可使用。

## 三种结局

- `WITNESS / 留证`：三段记忆均保留。
- `CLEAN CUT / 删净`：三段记忆均删除。
- `COUNTERCUT / 留下切口`：保留与删除混合存在。

另有一条不会增加第四结局的隐藏证人路径。发现线索保留在作品内部，公开说明不直接给出完整解法。

## 视觉与安全

- 第一阶段：青蓝、冷白、深黑。
- 第二阶段：洋红、紫色、橙红与多画幅。
- 第三阶段：黑、米白、橙红动态版画。
- 默认主画面换帧上限约 3 次/秒；“减少闪烁”进一步降至约 2 次/秒并停用结构故障帧。
- “减少动态”关闭快速旋转、连续位移和大部分过渡。
- 低性能桌面自动把碎片模式从 8 幅缩减到 4 幅；手机正常阶段使用 2 幅、介入后最多 3 幅，并简化滤镜。

- v2 的优化过程证据位于 `evidence/v2/`；从最终双击快捷方式实际启动后生成的交付证据位于 `evidence/final-shortcut/`，完整优化记录见 `优化记录-v2.md`。

## 本地构建

项目使用 React、TypeScript 与 Vite。正式构建命令：

```powershell
npm install
npm run build
```

正式产物位于 `dist/`。用户日常体验不需要执行这些命令。

## 内容与版权边界

18 个镜头来自六组为本作品生成的原创三联影像，源图保存在 `assets/source-storyboards/`，正式裁切保存在 `public/assets/shots/`。程序声音完全由 Web Audio 实时合成。参考视频只用于内部研究剪辑语法；其视频、音乐、人物、字幕和水印均未进入项目。
