# BLUE//DIVE《坠入蓝色世界》

![BLUE DIVE 界面预览](../docs/previews/04-blue-dive.jpg)

一段可由观众亲自潜入的蓝色情绪旅程。作品通过深度、扰动、停留与按住等动作，让记忆从水面进入回声、失语和蓝色核心，最后生成只属于本次体验的潜航记录。

本公开仓库保留当前正式版源码与必要素材，历史版本和重复构建未纳入仓库。

## 正式启动与关闭

普通观看不需要登录、输入命令或安装开发环境。

1. 在“科幻作品集”根目录双击 `打开《BLUE／／DIVE 坠入蓝色世界》.lnk`。
2. 浏览器会通过本机 `127.0.0.1` 打开正式构建，首选端口为 4361；端口被占用时，作品集运行器会安全选择其他可用端口。
3. 不再观看时，双击作品集根目录的 `关闭本地作品服务器.lnk`。

Windows 文件名不能包含半角 `/`，所以快捷方式文件名使用全角 `／`；网页中的作品名仍为 `BLUE//DIVE`。

请勿直接双击 `dist/index.html`。本作包含模块脚本，应始终通过本地作品启动器打开。

## 操作

- 入口：点击水滴，或按 Enter / Space，明确开始体验与程序生成声音。
- 鼠标：移动会扰动水层、文字折射、潜航者轮廓和碎片；点击留下水痕与水滴声；上下拖动改变深度。
- 滚轮：向下潜入，向上回到较浅的层级。
- 触控：单指移动和轻触产生扰动，上下拖动改变深度；在蓝色核心先移动唤醒碎片，再持续按住聚合记忆。
- 键盘：W / S 或上下方向键改变深度；A / D 或左右方向键改变横向扰动；在核心用 Space 按住；M 切换静音；R 切换减少动态；Esc 收起操作提示。
- 声音：仅在观众明确进入后，由 Web Audio 在本机实时合成；没有引用或分发参考视频音乐。右上角可随时静音。
- 减少动态：右上角“动态”按钮或 R 键可切换，也会尊重系统的减少动态偏好。

移动速度、停留时间、触碰次数、按住时长和输入方式会进入潜航记录，并改变结尾的回应方式、图形密度、空隙和水痕。记录卡可以下载为原创 PNG；“再潜一次”会回到静水入口。

## 本地与降级

- 正式运行不依赖登录、API Key、数据库、运行时 CDN 或在线字体，所有作品资源均从本机读取。
- WebGL 不可用或上下文丢失时，会切换为静态水层；叙事、深度操作、核心聚合与结尾记录仍可完成。
- 潜航者图像加载失败时，会隐藏失效图面并保留程序化水层，不阻断体验。
- 声音不可用或被浏览器限制时，视觉体验仍可完整继续。
- 桌面端为主要呈现；常见手机竖屏已设置触控、排版和性能适配。

## 原创与素材边界

参考视频只用于研究冷蓝色比例、黑场呼吸、纵向文字、局部切割和节奏密度。原视频、原音乐、人物、字幕、水印和任何画面帧均未复制、嵌入或进入正式构建。

`source-assets/diver-memory-source.png` 是为本作生成并保留的原创抽象潜航者母版，`public/assets/diver-memory.webp` 是本地优化版本。其余水面折射、颗粒、雨、碎片、光带、墨感和环境声均由本作代码实时生成。

## 源码与构建

源码位于 `src/`，正式产物位于 `dist/`，自动验证脚本位于 `tests/`。普通观看者不需要执行以下命令；仅供后续开发维护：

```powershell
npm ci
npm run build
npm run test:e2e
```
