# 《三小时之后 / AFTER THREE HOURS》设计定稿

## 作品命题

对象是一件给愿意把注意力交给未知几分钟的人使用的本地互动作品。它只做一件事：让抽象的“时间”获得可触摸、可留下、可带走的形状。

作品不是三小时倒计时，也不把效率包装成游戏。180 根纤维分别对应创作它的 180 分钟；观看者的停留、按压和移动会改变这些纤维，并在这台电脑上留下有限、可清除的痕迹。三种观察方式分别是“凝视”“偏离”“留下”。

## 三个布局方向

### A. 时间碑（采用）

```text
┌ title / seen ───────────────── sound / help ┐
│                                              │
│  180  ────────────────────────────────       │
│       ───────────────────────────────        │
│       ────────────╮──────────────────        │
│       ────────────┼── 180 minute fibres      │
│       ────────────╯──────────────────        │
│                                              │
│  act statement             [凝视 偏离 留下] │
└ session / traces ───────── save this moment ┘
```

单一全屏场域，没有滚动叙事、卡片或常规首屏。作品本体就是界面。

### B. 三联页

三个并排章节分别表现过去、现在、之后。叙事清楚，但会把连续的时间切成网站式分页，未采用。

### C. 档案桌

把每次动作变成可展开的记录条目。信息更丰富，但“档案列表”会抢走身体交互，未采用。

## 视觉系统

- 时间纸 `#E7E9E4`：主场背景，不做怀旧纸张纹理。
- 深纸 `#D3D7D0`：遮罩与层次。
- 石墨 `#182022`：文字和主要纤维。
- 雾 `#87928F`：辅助读数与未激活状态。
- 间隔蓝 `#315D70`：唯一品牌色，只用于“现在”、焦点和被留下的痕迹。
- 清光 `#F6F7F2`：高光与导出纸面。

字体角色：Bahnschrift SemiCondensed 承担英文标题和大数字；Microsoft YaHei UI 承担中文与正文；Cascadia Mono / Consolas 承担读数。全部使用 Windows 本机字体，不依赖网络。

## 签名元素

180 根横向分钟纤维构成一块“时间材料”。指针靠近时纤维并非追随光标，而是像被重量压弯；按住留下的记忆点会在今后打开作品时继续微弱地改变场。唯一持续移动的细线代表“现在”，它不模拟钟表速度，而以 180 秒完成一次穿行。

## 交互契约

- 移动：观察时间如何被靠近改变。
- 按住并缓慢移动：留下痕迹；高速乱划不会制造更多价值。
- 1 / 2 / 3：切换“凝视 / 偏离 / 留下”。
- S：开启或关闭本地生成声音；首次开启必须来自用户动作。
- E：把当前场保存为 PNG 作品页。
- L：打开三小时创作记录。
- ?：打开帮助。
- Esc：关闭覆盖层。

本地记忆仅使用浏览器 localStorage，不发送、不登录；最多保留 240 个压痕，用户可一键清除。减少动态、键盘焦点、窄屏布局和静音默认值均为正式体验的一部分。

## 自我审查

最初方向包含暖米色、衬线标题与橙红信号，这与常见的“文化展览网页”模板过近，也重复了既有作品的纸张/红色语言。定稿改为冷矿物灰、压缩无衬线和低饱和蓝；所有装饰性网格、发光、玻璃卡片与多段滚动说明均被删除。大胆之处只留在 180 根可被身体改变且会记住的纤维上。
