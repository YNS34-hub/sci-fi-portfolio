# 《三小时之后 / AFTER THREE HOURS》

一件由 180 根分钟纤维构成、会记住观看者停留与触碰的本地互动作品。

## 打开作品

正式交付后，在 Windows 桌面的“科幻作品集”文件夹中双击：

`打开《三小时之后 AFTER THREE HOURS》`

作品通过本机 `127.0.0.1:4411` 打开，不需要账号。声音默认关闭，第一次开启声音必须由观看者亲自点击。

## 如何观看

- 移动鼠标或手指：靠近 180 根分钟纤维。
- 按住并缓慢移动：留下一个本机压痕。
- `1 / 2 / 3`：切换“凝视 / 偏离 / 留下”。
- `S`：开启或关闭本地生成声音。
- `E`：把当前时间场保存为 1800 × 2400 PNG。
- `L`：查看真实三小时创作记录。
- `?`：打开说明；`Esc` 关闭覆盖层。

触屏界面也提供创作记录与保存按钮，不要求外接键盘。

## 隐私与离线边界

- 没有登录、API、分析代码、远程图片、在线字体或运行时 CDN。
- 观看痕迹只写入当前浏览器的 `localStorage`，最多 240 个。
- 作品不会上传痕迹；说明页内可以两次确认后清除。
- 浏览器拒绝本地存储时，作品仍能运行，只是不保留痕迹。
- PNG 在浏览器本机生成，下载文件名只含作品名与匿名场编号。

## 结构

- `src/art`：180 根分钟纤维的 Canvas 绘制与交互映射。
- `src/audio`：Web Audio 本地生成的低频声音场。
- `src/core`：时间结构、有限记忆与真实创作进度。
- `src/export`：1800 × 2400 PNG 作品页导出。
- `src/ui`：入口、观察方式、创作记录、帮助和无障碍交互。
- `tests`：单元、异常路径、桌面、窄屏、键盘、无障碍和网络边界测试。
- `docs/DESIGN.md`：设计方向、取舍与自我审查。
