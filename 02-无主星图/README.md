# 无主星图 / ATLAS OF THE UNCLAIMED

![无主星图界面预览](../docs/previews/02-atlas-of-the-unclaimed.jpg)

一件原创的交互式科幻宇宙作品：三颗虚构世界、九个真实电影拍摄感镜头、三次撤回人类介入的决定。它追问的不是“我们能否抵达”，而是“被发现的世界是否有权保持无主”。

## 作品内容

- **弥涌**：会随潮汐呼吸的盐质卫星；地质队撤回钻头，不带走样本。
- **葳昼**：双日雨林中的水纹记忆；语言学家关闭翻译器，不把模式冒充成人类语言。
- **斜暮**：沿晨昏线迁徙的生命；工程师拆除永久信标，让基础设施退出它们的地貌。
- **交互公约**：读者可为三个世界选择观察、命名或接触，并在本地生成一份不上传的“非接触公约”。

## 视觉资产

- 9 幅独立主镜头：每幅 `1920 × 823` WebP，并保留 PNG 母版。
- 3 张世界三联底片：每张约 `1920 × 2487`。
- 1 张九镜头系列总览：`1920 × 829`。
- 3 张独立光谱痕迹、1 张银盐底片材质、1 个物理放大镜、1 张 `1200 × 630` 社交预览图。

所有图像均为本项目原创生成资产。`public/worlds/` 按世界保存镜头、三联与母版；页面内提供系列总览和三联原图入口。

## 设计方法

项目以 Impeccable 4.0.3 建立设计方向和收尾审查，用 `cinema-dna-21x9x3` 的方法将每个世界拆成三个独立机位：不可解决的状态、撤回介入的动作、以及仍未被解释的余迹。界面采用档案光台、银盐底片、光谱显影和实体票据的视觉语法，避免常见霓虹 HUD 与游戏化科幻。

设计系统见 `DESIGN.md`，产品与叙事边界见 `PRODUCT.md`。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

质量检查：

```bash
npm run lint
npm run build
```

## 主要文件

- `app/AtlasExperience.tsx`：叙事、交互与公约生成器。
- `app/globals.css`：完整响应式视觉系统。
- `app/layout.tsx`：元数据、社交预览与设计方向契约。
- `public/worlds/`：九幅电影镜头、三联底片、光谱与母版。
- `DESIGN.md`：从最终实现反向提取的设计系统。
- `.impeccable/design.json`：Impeccable 设计系统侧车文件（仅本地审阅）。
