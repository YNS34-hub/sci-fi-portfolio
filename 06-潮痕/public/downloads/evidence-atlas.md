# 《潮痕》证物影像带 / EVIDENCE ATLAS

六张证物近景不是主镜头的裁切或缩略图，而是同一事件在另一观看位置留下的
物理证词。它们组成两组三联画：

- Triptych III：门封 / 空席 / 干圈
- Triptych IV：柜内 / 楔落 / 无主

统一要求：21:9、真人实景、真实材料、单一主动作加一个次要线索；不出现可读
文字、Logo、荧光界面、魔法光效、游戏道具陈列或灾难片奇观。

## E01｜门封 / THE SEAL

- 观看位置：维修人员手持的小型检查镜旁，几乎贴着黑色库门。
- 构图压力：漆层占据绝大部分画面，人物只剩一只手。
- 视线流量：从盐粒进入，沿开裂封层走到手套撬起的位置，再落到下面被掩埋的
  褪色救援橙底漆和一个儿童手掌尺度的浅压痕。
- 主动作：湿手套缓慢掀起一片厚黑封层。
- 次要线索：橙色底漆上的小手掌压痕明显比成人手小。
- 色彩：绿色黑、盐白、埋藏的褪色救援橙。

- 视线流量：从薄水中的椅脚反光进入，停在提起橙色面罩的手与仍未受力的空座垫，

## E03｜干圈 / THE DRY RING

- 构图压力：整齐湿润的圆形罐位里出现一个不可能的干燥负形。
- 视线流量：从四周凝露进入，被圆形重复结构收紧，停在唯一干圈，最后沿橙色软管

- 主动作：一只湿手套伸入空位，摸到仍然干燥的金属底板。
- 次要线索：所有相邻罐位都在滴水，只有空位无凝露。

- 视线流量：从黑暗柜内进入，落到母亲抵门的手，再穿过窄缝到女儿浸水的小腿，

- 主动作：母亲手掌把柜门重新压窄。
- 次要线索：柜内旧木板上有一条比当前水位更高的盐痕。
